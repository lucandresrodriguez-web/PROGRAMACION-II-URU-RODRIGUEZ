Trabajo Menu de Pokedex:

Descripcion general:
"Programa creado para la documentacion y desglose de un total de 150 pokemones distitnos, basandose en su tipo, poder de ataque y defensa, velocidad, generacion, si es legendario o no, etc".
En el menu creado se podran explorar acciones como:
1. Informacion desde numero de Pokedex
2. Buscar Pokemon por nombre de forma parcial(Por ejemplo "chu" dirige a Pikachu)
3. Buscar Pokemon por nombre exacto
4. Buscar por tipo 
5. Top de los 3 mas fuertes y mas debiles

Como ingresar?
1. Abrir carpeta por visual studio code
2. Usar el lenguaje de c++
3. Compilar el programa por medio de GitBash con el comando "g++ -std=c++11 POKEDEX.cpp -o pokedex"
4. Ejecutar menu por el comando de "./pokedex.exe
